# همدان (Hamdan) — نموذج أولي موسّع

## الوظائف الموجودة
- حساب مساحة مستطيل.
- حساب مساحة مثلث باستخدام صيغة هيرون.
- تسجيل آخر إحداثية GPS مع إذن المستخدم.
- إضافة نقاط يدويّاً عبر تسجيلها من GPS (حالياً).
- حساب مساحة مضلع من 3 نقاط أو أكثر بطريقة إسقاط محلي تقريبية.
- حفظ المشاريع والنقاط محلياً على الجهاز.
- تصدير نقاط المشروع إلى CSV داخل مجلد ملفات التطبيق.

## متطلبات البناء
- Android Studio حديث
- JDK 17
- Android SDK 35

## بناء APK
Windows:
`gradlew.bat assembleDebug`

Linux/macOS:
`./gradlew assembleDebug`

المسار المتوقع:
`app/build/outputs/apk/debug/app-debug.apk`

## قيود مهمة
- هذه نسخة أولية لم تُختبر على أجهزة فعلية ولم يُنفّذ بناء APK هنا.
- GPS يستخدم آخر موقع معروف فقط، وليس تتبعاً حياً أو مسحاً دقيقاً معتمداً.
- مساحة المضلع تقريبية، ويُفضّل للمساحات الكبيرة أو الأعمال الرسمية استخدام إسقاط مساحي مناسب والتحقق بجهاز مساحي.
- تصدير CSV يحفظ الملف داخل مجلد التطبيق الخارجي؛ ليس في مجلد التنزيلات العام.
- لا توجد خريطة تفاعلية في هذه النسخة بعد. يمكن إضافة خرائط فعلية في مرحلة لاحقة باستخدام مزود خرائط ومفتاح API إذا لزم.
